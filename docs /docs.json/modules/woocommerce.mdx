Приём криптоплатежей в магазине на WooCommerce. Без программирования.

**Совместимость:** WordPress 6.3+, WooCommerce 8.2+, PHP 8.0+.
**Файл модуля:** `oblodai-woocommerce.zip`.
**Где скачать:** кабинет [my.oblodai.com](https://my.oblodai.com) → «Загрузки».

---

## Шаг 1. Установите плагин

1. Войдите в админку WordPress (`https://ваш-сайт.ру/wp-admin`).
2. Слева выберите **Плагины → Добавить новый**.
3. Нажмите **Загрузить плагин** вверху страницы.
4. Нажмите **Обзор**, выберите файл `oblodai-woocommerce.zip`, затем **Установить**.
5. После установки нажмите **Активировать**.

<Note>
  Плагин появится в списке как «Oblodai – Crypto Gateway for WooCommerce».
</Note>

---

## Шаг 2. Введите ключи

1. Перейдите в **WooCommerce → Настройки → Платежи** (Settings → Payments).
2. Найдите в списке **Oblodai** и нажмите **Управление** (Manage).
3. Заполните:
   - **Enabled** — включите галочку.
   - **Public ID** — ваш публичный идентификатор из кабинета Oblodai.
   - **API secret** — ваш секрет из кабинета Oblodai.
   - (необязательно) **Method title** — как назвать способ оплаты на кассе.
4. Нажмите **Сохранить изменения** (Save changes).

<Note>
  Ключи (Public ID и API secret) берутся в кабинете [my.oblodai.com](https://my.oblodai.com) —
  см. [Регистрация и ключи](/guides/get-keys).
</Note>

<Note>
  При сохранении плагин **сам зарегистрирует вебхук** в Oblodai и запомнит секрет для проверки
  уведомлений. Отдельно ничего настраивать не нужно. Если увидите ошибку регистрации — проверьте
  ключи и что сайт доступен из интернета, и сохраните ещё раз.
</Note>

---

## Шаг 3. Проверьте

1. Откройте магазин, добавьте товар в корзину, перейдите к оформлению.
2. В способах оплаты выберите **Pay with Oblodai**.
3. Оформите заказ — вас перенаправит на страницу оплаты Oblodai.
4. Оплатите **реальную** небольшую сумму в крипте (песочницы нет).
5. Вернитесь в **WooCommerce → Заказы** — статус заказа должен смениться на «Выполнен»/«Обработка»
   автоматически (после того как оплата подтвердится и придёт вебхук).

## Настройки (подробно)

| Поле | Что делает |
|---|---|
| **Enabled** | Включает/выключает способ оплаты на кассе. |
| **Public ID** | Публичный идентификатор ключа (заголовок `X-Public-Id`). |
| **API secret** | Секрет для подписи запросов и авто-регистрации вебхука. Хранится на сервере. |
| **Method title** | Название способа оплаты, которое видит покупатель. |
| **Method description** | Подпись под названием на кассе. |
| **Invoice Lifetime** | Сколько времени действует счёт (1–12 часов). |
| **Host-to-Host** | Показывать выбор монеты/сети прямо на вашем сайте (иначе — на hosted-странице Oblodai). |
| **Accepted Networks** | Какие **сети** предлагать на кассе. **Пусто (по умолчанию) = предлагать всё, что отдаёт шлюз** — рекомендуемый вариант. |
| **Accepted Currencies** | Какие **монеты** предлагать на кассе. **Пусто = предлагать все, что отдаёт шлюз.** |
| **Subtract** | Кто платит комиссию приёма (0–100%): наценка на плательщика. |
| **Theme** | Оформление hosted-страницы оплаты: светлая / тёмная / своя. |
| **Debug log** | Подробные строки запрос/ответ в лог (WooCommerce → Статус → Логи, источник `oblodai`). По умолчанию выключено; ошибки пишутся всегда. Включайте, когда что-то не работает. |

### Какие сети и монеты можно выбирать

Оставьте **Accepted Networks / Currencies пустыми** — тогда покупателю предложат всё, что шлюз
поддерживает на момент оплаты, и список не придётся обновлять руками. Заполняйте, только если вы
сознательно хотите **сузить** выбор.

| | Значения |
|---|---|
| **Сети** | `ethereum`, `tron`, `bsc`, `polygon`, `arbitrum`, `base`, `avalanche`, `solana`, `ton`, `bitcoin` |
| **Монеты** | `USDT`, `USDC`, `DAI`, `BTC`, `ETH`, `BNB`, `POL`, `AVAX`, `TRX`, `SOL`, `TON` |

<Note>
  Регистр не важен — плагин сравнивает названия регистронезависимо.
</Note>

<Note>
  **Обновились со старой версии плагина?** Раньше на кассе **не показывалось ни одного способа
  оплаты**: списки сетей были записаны заглавными (`TRON`), шлюз отдаёт их строчными (`tron`), а
  сравнение было регистрозависимым — совпадений не находилось никогда. Плюс в списках стояли монеты
  из старого набора Heleket (DOGE, LTC, BCH, DASH, SHIB, MATIC, BUSD и т. п.), которых Oblodai **не
  принимает**. Это исправлено. Если вы правили списки руками — **очистите их** (пусто = предлагать
  всё) или впишите значения из таблицы выше.
</Note>

## Если что-то не работает

- **Способа «Oblodai» нет на кассе** → проверьте, что плагин активирован и в настройках стоит галочка
  **Enabled**.
- **После оплаты заказ не меняет статус** → сайт должен быть доступен из интернета (не `localhost`);
  зайдите в настройки способа оплаты и **сохраните ещё раз**, чтобы перерегистрировать вебхук.
- **«Could not register the webhook»** при сохранении → неверный `Public ID`/`API secret` или сайт
  недоступен снаружи. Исправьте и сохраните снова.
- **Ошибка подписи запроса (401)** → скопируйте ключи заново, без пробелов по краям.
- Общая диагностика — [Что делать, если не работает](/guides/troubleshooting) и
  [FAQ](/guides/faq-troubleshooting).
