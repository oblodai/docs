Приём криптоплатежей на форуме XenForo — за покупки и обновления аккаунта (Account upgrades /
подписки). Без программирования. Инструкция охватывает **обе** ветки движка: **XenForo 2.x** и
**XenForo 1.x** — шаги почти одинаковые, различия отмечены отдельно.

**Совместимость:**
- **XenForo 2.x** — XenForo 2.3.0+, PHP 8.2+. Файл модуля: `oblodai-xenforo-2.zip`.
- **XenForo 1.x** — XenForo 1.5.x. Файл модуля: `oblodai-xenforo-1.zip`.

**Где скачать:** кабинет [my.oblodai.com](https://my.oblodai.com) → «Загрузки».

<Note>
  Способ оплаты в обоих случаях называется **Oblodai**. Это правильный модуль Oblodai —
  `TC`/`PaygateHeleket` это старое внутреннее имя пакета, менять/пугаться не нужно.
</Note>

<Note>
  **Про подписки:** автопродление (recurring) этот способ оплаты не поддерживает — обновления
  аккаунта оплачиваются разово. Покупатель сам продлевает, когда срок истекает.
</Note>

## Шаг 1. Установите аддон

Сначала распакуйте нужный zip — внутри лежит папка `upload/`. **Загружать на сервер нужно
содержимое `upload/`, а не саму папку** (чтобы файлы легли в корень XenForo).

<Note>
  **Что такое FTP/SFTP?** Это способ загрузить файлы на сервер вашего сайта — через отдельную
  программу (например, бесплатную FileZilla) или через «Файловый менеджер» в панели вашего хостинга.
  Данные для входа (адрес сервера, логин, пароль) даёт хостинг. «Корень сайта» (корень XenForo) —
  это папка, где лежит файл `index.php` вашего форума; именно в неё нужно положить содержимое `upload/`.
</Note>

### XenForo 2.x

1. Распакуйте `oblodai-xenforo-2.zip`.
2. Загрузите **содержимое папки `upload/`** в корень вашего XenForo (по FTP/SFTP). После загрузки
   на сервере появится путь `src/addons/TC/PaygateHeleket`.
3. Войдите в админку (**AdminCP**) → **Add-ons** (Дополнения).
4. В списке найдите **TC - Paygate: Oblodai** и нажмите **Install** (Установить). Если аддон уже
   стоял — нажмите **Upgrade** (Обновить).
5. Дождитесь сообщения об успешной установке.

### XenForo 1.x

1. Распакуйте `oblodai-xenforo-1.zip`.
2. Загрузите **содержимое папки `upload/`** в корень форума. После загрузки появится путь
   `library/TC/PaygateHeleket`.
3. Войдите в **AdminCP** → **Install/Upgrade Add-on** (Установить/обновить дополнение из XML).
4. Укажите XML-файл аддона (`addon-tcPaygateHeleket.xml` из архива) и нажмите
   **Install Add-on** / **Upgrade Add-on**.
5. Дождитесь сообщения об успешной установке.

<Note>
  Если после установки в настройках нет провайдера/способа оплаты **Oblodai** — значит файлы
  загружены не в тот каталог. Проверьте, что на сервере появился `src/addons/TC/PaygateHeleket`
  (для 2.x) или `library/TC/PaygateHeleket` (для 1.x).
</Note>

## Шаг 2. Введите ключи

Понадобятся два значения из кабинета Oblodai: **Public ID** и **API secret** (один ключ работает на
всё). Дальше шаги различаются в зависимости от версии.

<Note>
  Ключи (Public ID и API secret) берутся в кабинете [my.oblodai.com](https://my.oblodai.com) —
  см. [Регистрация и ключи](/guides/get-keys).
</Note>

### XenForo 2.x — через платёжный профиль

1. **AdminCP** → **Setup** → **Payment profiles** (Платёжные профили).
2. Нажмите **Add payment profile** (Добавить платёжный профиль).
3. В списке провайдеров выберите **Oblodai**.
4. Заполните поля:
   - **Public ID** — ваш публичный идентификатор из кабинета Oblodai.
   - **API secret** — ваш секрет из кабинета Oblodai.
   - **Payment type** (Тип оплаты) — оставьте **Internal**, если хотите, чтобы выбор монеты/сети
     происходил на форуме. Выберите **Redirect**, чтобы покупателя сразу отправляло на страницу
     оплаты Oblodai.
   - **Disable currency selector** (только при типе **Redirect**) — включите, если выбор монеты и
     сети должен происходить целиком на сайте Oblodai.
5. Нажмите **Save** (Сохранить).

<Note>
  При сохранении модуль **сам зарегистрирует вебхук** в Oblodai и сохранит секрет для проверки
  уведомлений — отдельно ничего настраивать не нужно. Если сохранение выдаёт ошибку — проверьте
  ключи и что сайт доступен из интернета, и сохраните ещё раз.
</Note>

<Note>
  Не забудьте привязать этот платёжный профиль к нужным товарам/обновлениям аккаунта: их настройки
  находятся в разделах **Setup → User upgrades** и в соответствующих покупаемых сущностях.
</Note>

### XenForo 1.x — через опции аддона

1. **AdminCP** → **Options** (Настройки).
2. Откройте секцию **[TC] Paygate: Oblodai**.
3. Заполните:
   - **Public ID** — ваш публичный идентификатор из кабинета Oblodai.
   - **API secret** — ваш секрет из кабинета Oblodai.
   - **Payment type** — **Internal** (выбор монеты/сети на форуме) или **Redirect**
     (перенаправление на страницу Oblodai).
   - **Webhook secret** — **не трогайте**, поле заполняется автоматически при сохранении.
4. Нажмите **Save changes** (Сохранить).

<Note>
  Как и в 2.x, при сохранении опций вебхук регистрируется автоматически, а секрет записывается в
  поле **Webhook secret**. Вручную его вводить не нужно.
</Note>

## Шаг 3. Проверьте

1. Откройте форум под обычным пользователем и начните покупку (товар или обновление аккаунта).
2. В способах оплаты выберите **Oblodai**.
3. Выберите монету/сеть (при типе Internal) или перейдите на страницу Oblodai (при Redirect) и
   оплатите тестовую сумму в крипте.
4. Вернитесь в админку → **Payments** / лог транзакций: покупка должна отметиться как **оплаченная
   автоматически** после того, как оплата подтвердится и придёт вебхук.

<Note>
  Даже если покупатель закрыл вкладку сразу после оплаты, покупка обновится, когда придёт
  уведомление от Oblodai.
</Note>

## Настройки (подробно)

| Поле | Где | Что делает |
|---|---|---|
| **Public ID** | 2.x: профиль · 1.x: опции | Публичный идентификатор ключа (заголовок `X-Public-Id`). |
| **API secret** | 2.x: профиль · 1.x: опции | Секрет для подписи запросов и авто-регистрации вебхука. Хранится только на сервере. |
| **Payment type** | 2.x: профиль · 1.x: опции | `Internal` — выбор монеты/сети на форуме; `Redirect` — сразу на страницу оплаты Oblodai. |
| **Disable currency selector** | только 2.x (при `Redirect`) | Выбор монеты/сети происходит на сайте Oblodai, а не на форуме. |
| **Webhook secret** | только 1.x | Заполняется **автоматически** при сохранении; используется для проверки входящих вебхуков. Вручную не задаётся. |

**Поддерживаемые валюты счёта:** XenForo 2.x — USD, EUR, GBP, RUB, UAH; XenForo 1.x — USD, EUR, RUB.

<Warning>
  **BYN (белорусский рубль) шлюзом не поддерживается** — раньше он ошибочно значился в этом
  списке. Не поддерживаются также KZT, KGS, UZS.

  Аддон отправляет валюту вашего форума **как есть**. Если она не входит в число валют, в которых
  Oblodai умеет назначать цену, шлюз вернёт ошибку **`payment.unknown_currency`**, и платёж не
  создастся. В этом случае переключите валюту покупок форума на поддерживаемую. Полный список валют
  цены — 23 фиатных (USD, EUR, GBP, RUB, UAH, PLN, CZK, TRY, CNY, INR, BRL, CAD, AUD, CHF, AED, ZAR,
  MXN, IDR, THB, VND, NGN, JPY, KRW) плюс любые монеты; для XenForo актуальны те, что перечислены выше.
</Warning>

## Если что-то не работает

- **Способа «Oblodai» нет в списке** → аддон не установился или файлы загружены не туда. Проверьте
  наличие каталога `src/addons/TC/PaygateHeleket` (2.x) или `library/TC/PaygateHeleket` (1.x) и что
  аддон установлен в **Add-ons** (2.x) / загружен из XML (1.x).
- **После оплаты покупка не подтверждается** → сайт должен быть доступен из интернета (не
  `localhost`). Зайдите в платёжный профиль (2.x) или опции аддона (1.x) и **сохраните ещё раз** —
  вебхук перерегистрируется.
- **Ошибка при сохранении профиля/опций** → неверный `Public ID` / `API secret` или сайт недоступен
  снаружи. Исправьте и сохраните снова.
- **Ошибка подписи запроса (401)** → скопируйте ключи заново, без лишних пробелов по краям.
- Общая диагностика — [FAQ и устранение неполадок](/guides/faq-troubleshooting).
