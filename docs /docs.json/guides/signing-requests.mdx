---
title: "Подпись запросов"
description: "HMAC-SHA256 по трём заголовкам: основа безопасности и источник большинства ошибок на старте."
icon: "signature"
---

Каждый запрос подписывается HMAC-SHA256 по заголовкам `X-Public-Id`, `X-Timestamp` и `X-Signature`. Подпись считается только на вашем сервере.
