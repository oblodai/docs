Полный список кодов ошибок API Oblodai, сгруппированных по домену. Для каждого — HTTP‑статус, значение
и что делать. Это сводная страница для отладки: увидели код → нашли строку.

Общие правила обработки, HTTP‑классы и формат конверта ошибки — на странице
[Формат ответа и коды ошибок](/reference/basics-errors). Пошаговая диагностика по симптомам («что делать
если…») — [Что делать, если не работает](/guides/troubleshooting).

<Note>
  **Ветвитесь по `error.code`, а не по `message`.** Текст сообщения может меняться; код — контракт.
</Note>

---

## Как читать таблицу

- **HTTP** — статус ответа (отражает класс: `4xx` — ваша ошибка запроса, `5xx`/`503` — временная).
- **Повтор поможет?** — это и есть краткое «что делать»: «нет — &lt;как исправить>» значит сначала
  поправьте запрос; «да (backoff)» — временная ошибка, повторяйте с задержкой (повтор денег‑движущих
  операций безопасен благодаря [идемпотентности](/reference/basics-idempotency) — заголовку `Idempotency-Key`
  и/или `order_id`).

Если по коду непонятно, что делать, — найдите симптом в
[хабе диагностики](/guides/troubleshooting).

## auth — аутентификация

| Код | HTTP | Значение | Повтор поможет? |
|---|---|---|---|
| `auth.bad_timestamp` | 401 | `X-Timestamp` отсутствует или не число. | Нет — передайте unix‑секунды. |
| `auth.ip_not_allowed` | 401 | IP вне включённого [IP‑allowlist](/reference/api-allowlist). | Нет — добавьте IP в allowlist. |
| `merchant.bad_signature` | 401 | Подпись не совпала или `X-Timestamp` вне окна ±5 минут. | Нет — проверьте подпись; синхронизируйте часы (NTP). |
| `merchant.unknown_key` | 401 | Неизвестный или отозванный `X-Public-Id`. | Нет — проверьте ключ. |
| `merchant.wrong_key_kind` | 403 | Только для старых **раздельных** ключей: ключ без права на этот эндпоинт. Единый API‑ключ (`oblodai_…`) подходит везде. | Нет — используйте единый API‑ключ. |
| `auth.body_read` | 400 | Сервер не смог прочитать тело запроса (обрыв соединения при отправке). | Да — повторите запрос. |

Диагностика подписи — [Как подписать запрос](/guides/signing-requests).

## idempotency — заголовок `Idempotency-Key`

Приходят на создающих методах, если вы прислали заголовок
[`Idempotency-Key`](/reference/basics-idempotency).

| Код | HTTP | Значение | Повтор поможет? |
|---|---|---|---|
| `idempotency.in_progress` | 409 | Запрос с этим ключом **ещё выполняется**. Объект, возможно, уже создаётся. | Да (backoff) — повторите тот же запрос с тем же ключом чуть позже; получите исходный ответ. |
| `idempotency.bad_key` | 400 | Некорректный `Idempotency-Key` (пустой или длиннее 255 символов). | Нет — исправьте ключ. |
| `idempotency.unavailable` | 503 | Хранилище идемпотентности временно недоступно. Запрос **не выполнен** — молча продублировать операцию шлюз не станет. | Да (backoff) — повторите с тем же ключом. |

## batch — массовые операции

Ошибки **уровня батча** (весь запрос отклонён). Ошибки отдельных элементов приходят не сюда, а в
`items[].error` ответа [`/v1/batch/info`](/reference/batch-info) — там это коды соответствующего домена
(`payment.*`, `refund.*`, `payout.*`).

| Код | HTTP | Значение | Повтор поможет? |
|---|---|---|---|
| `batch.empty` | 400 | Массив элементов (`payments` / `refunds` / `payouts`) пуст. | Нет — добавьте элементы. |
| `batch.too_large` | 400 | Больше **5000** элементов в одном батче. | Нет — разбейте на несколько батчей. |
| `batch.bad_id` | 400 | `batch_id` не является корректным UUID. | Нет — проверьте идентификатор. |
| `batch.not_found` | 404 | Батч не найден (или принадлежит другому мерчанту). | Нет. |
| `batch.disabled` | 503 | Массовая обработка недоступна на этом шлюзе. | Да (backoff) — либо отправляйте операции по одной. |

Методы: [`/v1/payment/batch`](/reference/payment-batch), [`/v1/refund/batch`](/reference/refund-batch),
[`/v1/payout/batch`](/reference/payout-batch), [`/v1/batch/info`](/reference/batch-info).

| `discount.out_of_range` | 400 | `discount_percent` вне −99…99. | Нет — задайте значение в диапазоне. |

### accuracy — допуск недоплаты

| Код | HTTP | Значение | Повтор поможет? |
|---|---|---|---|
| `accuracy.out_of_range` | 400 | При `enabled: true` значение `accuracy_percent` вне 1–5 %. | Нет — задайте значение 1–5 %. |

### vrcs

| Код | HTTP | Значение | Повтор поможет? |
|---|---|---|---|
| `vrcs.read` | 400 | Ошибка чтения состояния VRCS. | Да (backoff) — повторите позже. |

## Вебхуки, автовывод, allowlist

### webhook

| Код | HTTP | Значение | Повтор поможет? |
|---|---|---|---|

## Общие серверные ошибки

| HTTP | Класс | Значение | Повтор поможет? |
|---|---|---|---|
| 429 | rate limit | Превышен лимит частоты. Тело `{"state":1,"message":"rate limit exceeded"}` + `Retry-After: 60`. См. [лимиты частоты](/reference/basics-ratelimit). | Да (backoff). |
| 503 | `unavailable` | Временная недоступность зависимости (напр. оракул курсов). | Да (backoff). |
| 500 | `internal` | Внутренняя ошибка, детали не раскрываются. | Да (backoff). |

<Note>
  **Транзиентные коды с HTTP 503.** Кроме перечисленных выше, при недоступности зависимостей могут
  прийти доменные коды класса 503 — например `rates.no_source` / `rates.non_positive` / `rates.deviation`
  (курс), `payout.freeze_unknown` (хранилище kill‑switch), `ledger.unavailable` (учёт). Все они —
  **временные**: повторяйте тот же идемпотентный запрос с backoff.
</Note>
