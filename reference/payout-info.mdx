Найти выплату по `uuid` (наш) или `order_id` (ваш).

**URL:** `https://api.oblodai.com/v1/payout/info` · **Аутентификация:** обязательна.

<Note>
  Примеры используют хелпер `call()` и переменные `$SECRET`/`$PUBLIC_ID` — их определение см. в
  [Как подписать запрос](/guides/signing-requests). Проще не писать подпись руками, а взять
  [SDK](/sdk/overview).
</Note>

---

## Параметры запроса

Нужен хотя бы один идентификатор.

<ParamField body="uuid" type="string">
  Идентификатор выплаты в Oblodai.
</ParamField>

<ParamField body="order_id" type="string">
  Ваш номер выплаты.
</ParamField>



---

## Пример запроса

<CodeGroup>

```bash cURL
BODY='{"order_id":"payout-1"}'
TS=$(date +%s)
SIG=$(printf '%s\n%s\n%s\n%s' "$TS" 'POST' '/v1/payout/info' "$BODY" \
  | openssl dgst -sha256 -hmac "$SECRET" -hex | sed 's/^.* //')
curl -s https://api.oblodai.com/v1/payout/info \
  -X POST -H 'Content-Type: application/json' \
  -H "X-Public-Id: $PUBLIC_ID" -H "X-Timestamp: $TS" -H "X-Signature: $SIG" \
  -d "$BODY"
```

```python Python
call("/v1/payout/info", {"order_id": "payout-1"})
```

```js Node.js
await call("/v1/payout/info", { order_id: "payout-1" });
```

</CodeGroup>

```json
{
  "state": 0,
  "result": {
    "uuid": "0c1f...e9",
    "order_id": "payout-1",
    "amount": "25",
    "currency": "USDT",
    "network": "tron",
    "address": "TXY...",
    "txid": "d0a1...b7",
    "status": "paid",
    "is_final": true,
    "approval_required": false,
    "source": "api",
    "created_at": "2026-07-10T12:00:00Z",
    "updated_at": "2026-07-10T12:04:00Z"
  }
}
```

---

## Коды ошибок

| Код | Значение |
|---|---|
| `400 payout.bad_uuid` | Некорректный `uuid`. |
| `400 payout.no_lookup` | Не передан ни `uuid`, ни `order_id`. |
| `404 payout.not_found` | Выплата не найдена (включая чужую выплату). |
