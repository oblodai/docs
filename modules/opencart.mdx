Приём криптоплатежей в магазине на OpenCart. Без программирования.

**Совместимость:** OpenCart **2.x**, **3.x** и **4.x**. Для каждой версии — **свой** файл модуля.
**Файлы модуля:**

| Версия OpenCart | Файл модуля |
|---|---|
| OpenCart **2.x** | `oblodai-opencart-2.zip` |
| OpenCart **3.x** | `oblodai-opencart-3.zip` |
| OpenCart **4.x** | `oblodai-opencart-4.zip` |

**Где скачать:** кабинет [my.oblodai.com](https://my.oblodai.com) → «Загрузки».

<Note>
  **Важно:** возьмите zip именно под вашу версию OpenCart. Свою версию видно внизу любой страницы
  админки или в **Панель управления → сведения о системе**. Модуль от другой версии не установится.
</Note>

---

## Шаг 1. Установите модуль

Во всех версиях модуль ставится одинаково — через встроенный установщик расширений.

1. Войдите в админку OpenCart (`https://ваш-сайт.ру/admin`).
2. В меню слева откройте **Расширения → Установка расширений** (Extensions → Installer).
3. Нажмите **Загрузить** (Upload) и выберите файл `oblodai-opencart-2.zip` /
   `oblodai-opencart-3.zip` / `oblodai-opencart-4.zip` — под вашу версию.
4. Дождитесь сообщения об успешной загрузке.

<Note>
  **OpenCart 2.x:** если установщик просит данные FTP — откройте **Система → Настройки → FTP** и
  заполните их (либо обновитесь до 2.3+, где FTP уже не требуется). В 3.x и 4.x FTP не нужен.
</Note>

<Note>
  **OpenCart 4.x:** после загрузки zip зайдите в **Расширения → Установка расширений** и убедитесь,
  что модуль в списке со статусом «Installed». Если рядом есть кнопка установки — нажмите её.
</Note>

---

## Шаг 2. Введите ключи

Здесь пути в админке немного отличаются по версиям.

**OpenCart 2.x и 3.x:**
1. Откройте **Расширения → Расширения** (Extensions → Extensions).
2. В выпадающем списке **Выберите тип расширения** выберите **Оплата** (Payments).
3. Найдите в списке **Oblodai** и нажмите зелёную кнопку **+** (Установить / Install),
   затем синий карандаш **Редактировать** (Edit).

**OpenCart 4.x:**
1. Откройте **Расширения → Расширения** (Extensions → Extensions).
2. В фильтре **Выберите тип расширения** выберите **Оплата** (Payments).
3. Найдите **Oblodai** и нажмите **Редактировать** (Edit) — иконку карандаша.

Дальше — одинаково для всех версий. Заполните поля:

- **Public ID** — ваш публичный идентификатор из кабинета Oblodai.
- **API secret** — ваш секрет из кабинета Oblodai.
- **Payment Method Enabled** (Способ оплаты включён) — установите **Enabled** / «Включено».
- **Order status** — статусы заказа, которые модуль будет ставить (см. таблицу ниже). Оставьте
  значения по умолчанию, если не уверены.

Нажмите **Сохранить** (кнопка с дискетой в правом верхнем углу).

Ключи (Public ID и API secret) берутся в кабинете [my.oblodai.com](https://my.oblodai.com) — см. [Регистрация и ключи](/guides/get-keys).

<Note>
  При сохранении модуль **сам зарегистрирует вебхук** в Oblodai и запомнит секрет для проверки
  уведомлений об оплате. Отдельно ничего настраивать не нужно. Если вверху появится предупреждение
  «Oblodai webhook registration failed» — проверьте ключи и что сайт доступен из интернета, и
  **сохраните ещё раз**.
</Note>

---

## Шаг 3. Проверьте

1. Откройте магазин, добавьте товар в корзину, перейдите к оформлению заказа.
2. На шаге способа оплаты выберите **Oblodai**.
3. Оформите заказ — вас перенаправит на страницу оплаты Oblodai.
4. Оплатите тестовую сумму в крипте.
5. Вернитесь в админку, в **Продажи → Заказы** — статус заказа должен смениться автоматически
   (сначала на «ожидание оплаты», затем на «оплачено»), когда придёт вебхук от Oblodai.

## Настройки (подробно)

Названия полей — как в админке модуля (одинаковы для 2.x / 3.x / 4.x):

| Поле | Что делает |
|---|---|
| **Public ID** | Публичный идентификатор ключа (заголовок `X-Public-Id`). |
| **API secret** | Секрет для подписи запросов и авто-регистрации вебхука. Хранится на сервере. |
| **Title** | Название способа оплаты, которое видит покупатель на кассе. |
| **Invoice lifetime (seconds)** | Сколько действует счёт, **в секундах** (например, `3600` = 1 час). |
| **Payment Method Enabled** | Включает/выключает способ оплаты на кассе. |
| **Ordering** (Sort order) | Порядок в списке способов оплаты. |
| **Order status** | Базовый статус заказа после создания счёта. |
| **Pending status** | Статус, пока оплата в ожидании/подтверждается. |
| **Paid status** | Статус после успешной оплаты. |
| **Invalid status** | Статус при ошибке/недействительной оплате. |

## Если что-то не работает

- **Способа «Oblodai» нет на кассе** → убедитесь, что в настройках стоит **Payment Method Enabled =
  Enabled**, и что назначены **статусы заказов** (Order / Pending / Paid / Invalid). В OpenCart 2/3
  проверьте, что расширение вообще **установлено** (зелёная **+** в списке способов оплаты).
- **После оплаты заказ не меняет статус** → сайт должен быть доступен из интернета (не `localhost`);
  откройте настройки модуля и **сохраните ещё раз**, чтобы перерегистрировать вебхук.
- **«Oblodai webhook registration failed»** при сохранении → неверный **Public ID** / **API secret**
  или сайт недоступен снаружи. Исправьте и сохраните снова.
- **Ошибка подписи запроса (401)** → скопируйте ключи заново, без пробелов по краям.
- **Установщик OpenCart 2.x ругается на FTP** → заполните **Система → Настройки → FTP** или
  обновите OpenCart до 2.3+.
- Общая диагностика — [FAQ и устранение неполадок](/guides/faq-troubleshooting).
